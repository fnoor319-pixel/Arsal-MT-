INTENTIONALLY NOT FAKED / NOT ENABLED YET
------------------------------------------
A. Real economic calendar / headline sentiment provider
   The adapter is complete, but no provider key/feed was supplied. The included
   news file is UNCONFIGURED. SPARTAN_NEWS_HARD_GATE therefore defaults False so
   the existing running demo bot is not frozen. Connect a reliable provider,
   then set it True.

B. OpenAI live reviewer
   Code is complete but defaults OFF. Configure OPENAI_API_KEY + OPENAI_MODEL,
   then enable SPARTAN_LLM_REVIEW_ENABLED. Structured output uses the current
   OpenAI Responses parsing pattern. Python remains final safety authority.

C. XGBoost / RandomForest / LSTM / GRU live models
   These were NOT invented or dropped into execution without a trained,
   out-of-sample validated model. The existing persistent online SuperLearner is
   retained as the ML vote. Advanced offline models should only be promoted after
   proper leakage-safe training, walk-forward testing, shadow and demo validation.

D. COMEX GC / NYMEX CL central-market reference flow
   The current system uses the broker's MT5 XAUUSD/USOIL DOM/ticks. A separate
   futures data subscription/feed was not supplied, so no claim is made that MT5
   CFD DOM represents the full global order book.

E. Oil absolute ATR threshold
   Gold 0.50 is implemented. Oil is left at 0.0 until the actual broker quote
   format/history is calibrated; existing spread/ATR and regime filters still run.

F. Forced 1.0 ATR SL / 1.5 ATR TP
   The switch is implemented but defaults OFF because changing only live exits
   would invalidate the existing backtest/live parity. Backtest dedicated Spartan
   strategies with that geometry first, then enable SPARTAN_FORCE_FIXED_ATR_EXITS.

2. Run 01_INSTALL.bat (requirements now include OpenAI/Pydantic for optional AI).
3. Run 10_OFFLINE_SELF_TEST.bat.
4. Run 02_MT5_DIAGNOSTIC.bat.
5. Run 16_SPARTAN_PRO_STATUS.bat.

features. The purpose of the added gates is to make decisions more structured,
