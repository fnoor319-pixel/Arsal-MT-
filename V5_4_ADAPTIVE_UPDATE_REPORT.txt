V5.4 ADDITIONS
1. Persistent direction/regime-specific adaptive_trade_memory.
2. Existing closed demo_positions are bootstrapped into adaptive memory once.
3. Per-setup loss cooldown: 3 minutes after first live loss, then exponential
   cooldown up to the configured 2-hour maximum.
4. Duplicate identical setup block while that setup already has an open DEMO
   position.
5. Repeated-loss recovery confirmation: after two recent consecutive losses the
   signal needs stronger ensemble votes/dominance before re-entry.
6. Confidence score using smoothed win rate + average R + recency-weighted EWMA
   reward + consecutive-loss penalty.
7. Memory recency decay back toward neutral and loss-streak session reset so a
   setup is not permanently banned.
8. Adaptive candidate-ranking adjustment, so recent live performance affects
   which approved/trial strategy is selected.
9. Entry-context memory (ATR, RSI, EMA relationship, volatility, spread/ATR,
   DOM, votes/weights and execution tier) stored with new DEMO positions.
10. adaptive_learning_events audit table for every newly closed DEMO trade.
11. Adaptive risk multiplier. Base risks remain unchanged. Upsizing requires at
   least 8 positive live observations and confidence >= 0.62. Approved target
   risk may scale to at most 0.45% equity (existing 0.50% hard ceiling remains);
   trial target risk may scale to at most 0.10% (existing 0.35% ceiling remains).
   Broker minimum/step/maximum and stop-distance sizing still decide final lot.
12. Screen 4 library output now shows adaptive observations/confidence/loss
   streak. Screen 5 logs learning blocks, confidence and risk multiplier.
13. 11_STATUS_REPORT now includes adaptive learning totals.
14. Five visible windows, supervisor/startup structure, DEMO hard lock, existing
   strategy generator, backtester, shadow validator and execution tiers retained.
