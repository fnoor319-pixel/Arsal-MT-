V10.0 SUPERHUMAN SCALP OS — DEMO ONLY

PURPOSE
V10 does not add another chain of serial vetoes. It adds a fast local expert router
beside the existing Micro Hunter. If the original hunter has no fresh setup, V10 scans
eight complementary intraday archetypes and sends the strongest candidate through the
existing V9/V9.2 execution, risk, broker, exit and learning stack.

FAST EXPERT ARCHETYPES
1. trend_pullback
2. momentum_breakout
3. squeeze_release
4. liquidity_sweep_reclaim
5. failed_breakout_reversal
6. vwap_mean_reversion
7. range_edge_rotation
8. exhaustion_snapback

WHY THIS DESIGN
Most intraday behavior can be described as trend/continuation, range/mean-reversion,
breakout/volatility expansion, compression, failed breakout/liquidity sweep, or
exhaustion/transition. V10 uses a regime router to prefer the specialist suited to the
current state. Experts are scores, not eight new mandatory permissions.

LUNA ROLE
Luna stays a selective meta-brain through the existing V9 advisory path. The local fast
brain does not wait for Luna on every candidate. High-quality setups can still be sent as
one compact market packet; Luna's answer adjusts confidence/risk and is logged for later
value-add analysis. Luna is not treated as a live-data oracle: current MT5/tick/DOM state
must be supplied by the machine.

LEARNING
Every V10 playbook is stored under the existing V9.2 contextual memory:
  symbol + playbook + side + regime + session
so actual broker outcomes automatically build specialist memory, MFE/MAE, dynamic exits,
rejected-trade counterfactuals, and champion/challenger evidence.

SAFETY / CAPACITY
- 100 trades/symbol/day remains a SAFETY CEILING, not a quota.
- V9.2.1 symbol-local 5-loss freeze is preserved.
- Portfolio daily-loss and peak-drawdown hard stops are preserved.
- No martingale or loss-doubling is added.
- Existing spread, fresh-price, sizing, correlation, news and broker checks remain.
- Base risk is NOT increased by this update.

INSTALL
1. Run 09_STOP_ALL_WINDOWS.bat once.
2. Run 15_BACKUP_LEARNING.bat.
3. Copy all files from this update's TM_V6_SCALP_INTELLIGENCE_DEMO folder into the
   existing same folder and choose Replace.
4. KEEP .env, trading_machine.db, data, reports and backups.
5. Run 10_OFFLINE_SELF_TEST.bat; it must end with OFFLINE SELF TEST PASSED.
6. Run 46_V10_SUPERHUMAN_SCALPER_STATUS.bat.
7. Run 00_RUN_ME_DEMO.bat.

Do not judge V10 from trade count alone. Judge each expert by broker-DEMO expectancy,
profit factor, average R, drawdown, MFE/MAE and execution cost after enough outcomes.
